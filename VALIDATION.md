# Iris validation

The current distribution uses Particle Sliders core 0.15.2 and ParticleGAN 0.11.1.
See the [CPU software check](README.md#cpu-software-check) for native tiny-model
training and RAW response replay.

The [archived validation notes](https://github.com/HyperGAN/iris-particle-sliders/blob/9fea40c6a942c4f3fc686486df9a7133da43f6d7/VALIDATION.md) and
[archived evidence tree](https://github.com/HyperGAN/iris-particle-sliders/tree/9fea40c6a942c4f3fc686486df9a7133da43f6d7/evidence) preserve the earlier cohorts,
their installation records, and their original validation scope.
